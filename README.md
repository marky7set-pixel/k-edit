# K-Edit · ادیت کلید

دو برنامهٔ مستقل و کاملاً آفلاین (بدون اینترنت، بدون نسخهٔ وب، بدون اتصال به سایت یا اپ کلید؛ فقط ظاهرش از کلید الهام گرفته):

- **اندروید** (`android/`): فایل APK
- **ویندوز** (`desktop/`): فایل نصب و فایل بدون نصب

هر دو دو کار می‌کنند: **عکس → WebP** (برش، چرخش، آینه، نور و رنگ، اندازه، کیفیت هوشمند/بی‌افت/دستی) و **ویدیو → GIF** (برش کادر، بریدن زمان از جلو و عقب، فریم، عرض، سرعت، تکرار).
رابط هر دو در `ui/` است: `desktop.html` برای ویندوز و `mobile.html` برای اندروید. فایل‌های آماده در بخش Releases ساخته می‌شوند.
