# K-Edit · ادیت کلید

دو برنامهٔ کاملاً آفلاین با ظاهر کلید (سرمه‌ای و طلایی):

- **اندروید** (`android/`): فایل APK
- **ویندوز** (`desktop/`): فایل نصب و فایل بدون نصب

رابط هر دو در `ui/` است: `mobile.html` برای گوشی و `desktop.html` برای ویندوز؛ منطق مشترک در `ui/js/editors.js`.

- **عکس:** برش، چرخش، آینه، نور و رنگ، ۲۰ افکت، هوش مصنوعی (بهبود، ۲×، ۳×، ۴× با شدت طبیعی/متعادل/قوی)، «وضوح هیچ‌وقت کم نشود»، خروجی AVIF، WebP، JPG، PNG
- **ویدیو:** کات، کادر، سرعت، افکت، خروجی MP4، WebM، WebP متحرک، GIF

هوش مصنوعی: وزن‌های رسمی Real-ESRGAN general x4v3 و wdn-x4v3 (BSD-3-Clause) هنگام ساخت دانلود و تبدیل می‌شوند (`ci/ai_weights.py`).
ساخت خودکار: `deploy/src.json` یا `version.txt` که عوض شود، GitHub فایل‌ها را در بخش Releases می‌سازد.
